# 漏出指標の読み直し — 率から額へ

**状態**：完了。C 着手前の前提整理。

閉じた世界で世界物価を動かすのは、財政1単位あたりの漏出「率」ではなく、
世界財市場に届く需要の「額」である。Phase 1〜3 は率で報告していたので、
その順位を v8 に持ち込む前に読み直した。

**新規実行は最小限に留めた**：Phase 3 は保存済み `cheap_levels.jsonl` をそのまま
再集計した。Phase 1 は輸入／対外資産の分解を保存していないため、
4アーキタイプについてのみ再計算した（`analysis/v8_releak.py`）。

---

## 1. 二つの補正

読み直しには2つの補正が要り、**互いに逆方向に効く**。

### 1.1 率 → 額

率は財政コストで割った値である。厚生等価の CLT は対象現金の約 0.40 倍の
財政規模なので、**率は額に対して約2.5倍に膨らむ**。

### 1.2 漏出のうち財を買う部分

Phase 1 の `leak` は**輸入 + 対外資産購入**である。
世界財市場に届くのは輸入だけで、対外資産として出ていく資金は財を買わない。

> **Phase 1 と Phase 3 は同じものを測っていなかった。**
> Phase 3 の `cheap_levels.jsonl` は `imp_c − base.imp_c + imp_gov`、
> つまり**輸入のみ**を記録していた。Phase 1 の `leak_abs` は
> 対外資産を含む。両者の数値を並べて比較することはできない。

## 3. 資本流出はどこへ行くか（レビュー指示2）

### 3.1 v8 の実装に穴があった

**`d_fa` は漏出ログに記録されるだけで、v8 の動学に一切入っていなかった。**
世界を財については閉じたのに、資本については v7 のまま開いていた。
資本流出が「どこかへ消える」構造が残っていた。

修正した。`d_fa` を資本収支の希望流出に算入し、
`balanced_capital_flows` の閉包を通して他ブロックの流入にする。

```
want = openness · cap_sens · (r − rp − r_w) − 家計の対外資産購入
net_k = balanced_capital_flows(want, weights)    # Σ net_k = 0
```

主要結果への影響は 0.3% 以内（全員UBI u=0.01 で P_w 1.4613 → 1.4650）。

### 3.2 資本流入は財需要になるか

現行の実装では、資本流入 `flow` は受入国で3つに作用する：

| 経路 | 効果 |
|---|---|
| `de = −2·flow·e` | 為替（増価） |
| `growth += 0.15·flow` | 成長 |
| `K += flow` | 資本ストック |

**同期には財需要にならない。** 成長を通じて間接的に将来の輸入を増やす。
D 単独 UBI（u=0.01）で世界需要は 6年目 +0.00047 → 30年目 +0.00185 と累積する。

> **仮定として明記する**：**資本流入は請求権の購入であり、
> 到着した期に世界財需要を増やさない。** 財需要への到達は資本ストックと
> 成長を経由する間接経路のみである。
>
> 根拠：家計が対外資産を買うのは消費を先送りするためであり、
> 受入側でそれが即座に財の購入に転換されるなら、そもそも貯蓄になっていない。
> ただしこれは会計上の恒等式ではなく**仮定**である。

### 3.3 仮定の感度

`G.capital_inflow_to_demand`（既定 0.0）で、流入の一定割合を
到着期の世界財需要に直接算入できるようにした。

| 割合 | UBI の P_w | CLT の P_w | 比 |
|---|---|---|---|
| 0.00 ★ | 1.4650 | 1.1582 | 1.265 |
| 0.25 | 2.0094 | 1.2453 | 1.614 |
| 0.50 | 4.2545 | 1.3904 | 3.060 |
| 1.00 | 発散 | 6.9748 | — |

> **この仮定は結論を弱めない。強める。**
> 資本流入を財需要に算入するほど、UBI と CLT の差は**広がる**。
> UBI の漏出は対外資産の比率が高く（D で fa 率 +0.102）、
> CLT は負（−0.145）なので、fa を需要に数え直すと
> UBI の押し上げだけが増えるためである。
> 1.0 では資本流入→需要→物価→流入の正のフィードバックが発散する。
>
> レビューの懸念（「UBI の漏出の多くが fa なら、この扱いが
> 『UBI は世界物価を押し上げない』という結論を左右する」）は、
> **逆方向に作用する**。現行の仮定 0.0 は UBI に最も有利な扱いであり、
> それでも UBI の押し上げが最大である。

## 4. Phase 1 と Phase 3 は比較できない量を測っていた（レビュー指示3）

レビュー側が両者を並べて読んでいた箇所があるとのことなので、照合した。
**両者は矛盾しており、原因は Phase 3 §5 の実装にある。**

### 4.1 症状

| 出典 | 比較 | 指標 | 結果 |
|---|---|---|---|
| Phase 1 表1 | CLT 対 cash_t | `leak_abs`（imp+fa、30年動学） | **CLT が小さい 99.5〜100%** |
| Phase 3 §5 | CLT 対 cash_t | 輸入のみ（**静学1期**） | **CLT が大きい 12/12** |

比較対象も母集団も問題ではない。両方 CLT 対 cash_t である。

### 4.2 原因：Phase 3 §5 は静学1期を測っていた

`analysis/legacy/phase3_cheap.py` の `levels()` は
`hetero_household_block` を `years_since_start` を渡さずに呼んでおり、
既定値 `1e9`、すなわち**建設完了後の定常状態の1期分**を測っている。

`hetero_household_block` は建設輸入をストック水準に比例した量として
毎期計上し続ける（`yrs=10` で `imp_gov=0.000150`、`yrs=1e9` でも同じ）。
静学スナップショットではこれが恒久フローとして扱われる。

動学（`core.simulate`）では建設は初期に集中し、その後の30年で薄まる。

### 4.3 切り分け

| 測り方 | 母集団 | CLT > cash_t（輸入のみ） |
|---|---|---|
| 静学1期（Phase 3 §5 の方法） | 12ブロック | **12/12** |
| 静学を30年積分 | 12ブロック | 7/12 |
| **30年動学** | 12ブロック | **0/12** |
| **30年動学** | アーキタイプ | **0/4** |

**母集団の差ではない。静学か動学かの差である。**
同じ12ブロックで、静学1期なら 12/12、動学なら 0/12 と完全に反転する。

### 4.4 結論に対する影響

> **Phase 3 §5 の「CLT は建設輸入で漏出が大きく不利」は、
> 30年の動学では成立しない（0/12）。**
> 成立するのは「建設が完了した後の定常状態の1期」を切り取ったときだけである。
>
> ただし §5 の**主結論そのもの**（「fx 勾配はコスト差が担う。
> 非逃避性が独立に寄与する証拠は得られなかった」）は、
> 漏出の大小ではなく内生ストレス（ΔPV債務・リスクプレミアム・減価）の
> 比較に基づいており、**この訂正では変わらない**。
>
> 影響を受けるのは §6.1 の記述である。
> 「CLT は移行期に建設輸入で漏出が大きいので、
> 『fx が高いほど CLT 有利』を『fx が高いほど漏出のペナルティが重い』が
> 相殺してしまう」という説明は、**動学では漏出が大きくないので成り立たない**。
> 還元形で水準効果が縮む理由は別に求める必要がある。

### 4.5 Phase 1 の結論は維持される

Phase 1 表1（CLT の漏出が現金より小さい割合 99.5〜100%）は
30年動学の `leak_abs` に基づいており、本節の検証と整合する。
ただし `leak_abs` は imp+fa の合算なので、
**閉じた世界での「世界市場への圧力」としては (c) の輸入のみを使うべきである**。
順位は §2 の通り (b)→(c) で変わらないので、Phase 1 の結論は順位としては保たれる。

## 5. V8-A の結果との整合

V8-A（表2）では CLT の世界物価押し上げが最小（+0.120 対 UBI +0.423）だった。
本節の「額でも CLT の漏出が最大」と矛盾するように見えるが、両立する。

- **§3 の比較は厚生等価**：同じ厚生を CLT は約0.40倍の財政規模で達成するが、
  その小さい財政の中で輸入集約度が高い（建設輸入）。漏出額は現金より大きい。
- **V8-A の比較も厚生等価**だが、測っているのは世界**総**需要への寄与である。
  CLT の財政規模が小さいため、絶対額としての世界市場への需要増が最小になる。

数値が違うのは u（0.05 対 0.01）と、V8-A が世界を閉じたうえで
価格の一般均衡効果を含むためである。**符号が食い違っているわけではない。**

## 6. 今後の報告方針

- **主指標は額**：世界財市場に届く需要の水準（対GDP比、および世界総需要に占める割合）。
- **率も並記する**：`leak_abs` / `leak_per_fiscal` / `leak_per_welfare` は
  **「開いた世界における一国指標」**として保持する。廃止しない。
- **輸入と対外資産を分けて報告する**：合算した `leak` は
  世界財市場への圧力を測る量として不適切である。
- **Phase 1〜3 のレポートは書き換えない。** それらは開いた世界・GDP連動給付という
  前提の下での結果であり、前提ごと保存する（CLAUDE.md の方針）。
  本ファイルが読み直しの記録である。
