# PHASE V8-A — 世界を閉じる／世界インフレ

**状態**：設計 A・B を実装。受け入れ条件を充足。C・D 着手前にレビュー待ち。

★ = 主系列。

---

## スコープ（本モデルが扱う範囲）

**扱うのは、国家が経済的に維持できなくなる手前までである。**
決済制約に拘束され、輸入が圧縮され、受給者が基礎需要を満たせなくなり、
債務超過や決済不能に至る、というところまで。

**経済破綻の後に起きることは扱わない。**
政府の権威と正当性の喪失、内乱、その外部化としての戦争、難民の流出入。
これらは社会・政治の領域であり、モデルに入れれば係数の置き方が
結論を決めることになる。

示せるのは、ある配置がどれだけの圧力を生み、
どの構造のブロックが先に限界に達するかまでである。
**現実の破綻の可否も、その後の展開も、本モデルは予測しない。**

## 用語について

**「CLT」は「非逃避的な現物資産として供給される住宅」の代表例である。**
コミュニティ・ランド・トラストという特定の制度形態の忠実な再現ではない
（借地条件・再販価格の算式・ガバナンス構造はモデルに入っていない）。
モデルが表現しているのは、議論が依拠する二つの性質だけである：
給付が金額ではなく実物量であること、その支出が輸入ではなく国内建設に
偏って向かうこと。この二つを持つ制度なら、モデル内では同じ挙動を示す。

**「バウチャー」は対照であって政策提案ではない。**
現物の食料給付が現金と等価になる領域（インフラマージナル）と
そうでない領域を確定するために置いている。

## 1. 実装したもの

### 1.1 v7 の凍結

`legacy/v7/` に v7 の `model/` 全体を凍結し、回帰テストを `tests/legacy/`、
分析スクリプトを `analysis/legacy/` に移した。**legacy は 278 passed / 3 skipped**
で、v6 のビット単位再現を含めて健全である。

CLAUDE.md の「v6 をビット単位で再現」は指示 F に従って撤回し、
代わりに (a) legacy 系統の維持、(b) v8 独自の恒等式テスト、
(c) 移植の正しさのテスト、を要求する形に書き換えた。

### 1.2 A — 世界を閉じる（`model/trade.py`）

- **貿易シェア行列** `S[i][j]`：規模 × 開放度で構成、時間不変、行和1・対角0。
- **加総条件**：`X_j = Σ_i S[i][j]·M_i` なので世界の輸出＝輸入が定義から成立。
- **資本収支の閉包**：各ブロックの希望流入の総和を規模按分で差し引き、`Σ net = 0`。
- **対外純資産**：`ΔNFA_i = CA_i + KA_i`、`Σ ΔNFA = 0`。

### 1.3 B — 世界インフレ（`model/world.py`）

- 世界容量 `Ysup_w` は**需要加重**の平均成長率で伸びる（§7.1 の修正）。
- 需給ギャップ `D_w/Ysup_w − 1` が世界価格 `P_w` の変化率を決める。
- 各ブロックは `e_i · P_w` を輸入価格として受け取り、輸入比率に応じてインフレに転嫁。

### 1.4 移植（`household.py`, `heterogeneous.py`）

貿易財価格を世界価格から合成する形に変えた：

```
v7:  pF = 1 + m_F·(e − 1)
v8:  pF = (1 − m_F)·1 + m_F·(e · P_w)
```

**`P_w = 1` で両者は代数的に同一**である。`tests/test_port_from_v7.py`（53件）が
v7 と機械精度で一致することを固定している（Phase 2 の家計異質化・建設上限を含む）。

## 3. 主要結果

### 3.1 給付していないブロックも世界物価を通じて影響を受ける

D だけが給付した場合（u=0.01）：

| ブロック | GDP | インフレ | 対外純資産 |
|---|---|---|---|
| A（基軸） | 1.8060 → 1.8090 | +0.0160 → +0.0160 | **+0.537** |
| B（先進） | 1.4330 → 1.4350 | +0.0200 → +0.0210 | +0.156 |
| C（新興） | 1.1320 → 1.1320 | +0.0320 → +0.0330 | −0.311 |
| D（途上・給付） | 0.4270 → 0.4290 | +0.0390 → **+0.0510** | −0.382 |

世界物価 1.0388 → 1.0950。**D の漏出は消えずに A・B の輸出収入として現れる**
（NFA が A で +0.537、B で +0.156）。v7 ではこれがモデルの外へ消えていた。

### 表2：同じ厚生を達成する様式でも、世界市場への圧力は異なる ★

全ブロックが厚生等価の給付を行った場合（u=0.01）：

| 様式 | 世界物価 | 無給付超過 | D の財政規模 | D の漏出/財政 |
|---|---|---|---|---|
| UBI | 1.4613 | +0.4225 | 0.01000 | 0.293 |
| 食料バウチャー | 1.2602 | +0.2215 | 0.00500 | 0.299 |
| 対象現金 | 1.2442 | +0.2054 | 0.00500 | 0.298 |
| **CLT** | **1.1586** | **+0.1198** | **0.00208** | **0.349** |

**CLT は漏出率が最も高いのに、世界物価への押し上げが最小である。**

v7 の枠組みでは矛盾に見えるが、閉じた世界では両立する。CLT は同じ厚生を
**財政規模 0.00208**（UBI の約1/5）で達成するため、漏出「率」が高くても
漏出「額」が小さい。世界市場に届くのは率ではなく額である。

> **これは v7 では測れなかった量である。** v7 では漏出は各国の収支から差し引かれる
> だけで、世界のどこにも現れなかったので、「世界市場への圧力」という概念が存在しなかった。

図3（`figures/v8a/fig3_modalities`）が経路と水準を示す。
右パネルは無給付比で描いてある（水準で描くと共通部分が支配して差が潰れるため）。

## 4. 想定外の結果

### 4.1 CLT の評価軸が変わった

CLAUDE.md §E は CLT の再定義を (i) インフレ下でも実質価値が保たれる、
(ii) 輸入決済を必要としない割合が高い、の二点としている。
A/B の段階では (i) はまだ実装していない（C の範囲）が、
**(ii) に相当する効果が漏出率ではなく財政規模の小ささから出ている**。

Phase 3 では「漏出率」で様式を比較し、CLT が不利になる領域を報告した。
閉じた世界では**率ではなく額が世界物価を動かす**ので、比較の軸が変わる。

> **読み直しを実施した。`reports/V8_RELEAK.md` を参照。**
> 結論：様式の順位は4ブロックすべてで**完全に逆転**する
> （率では ubi > cash_t > voucher > clt、額では clt > cash_t > voucher > ubi）。
> Phase 3 §5 の「CLT は建設輸入で漏出が大きく不利」は額でも 12/12 で成立するが、
> 差は +0.246（率）→ +0.044（額）へ約1/5.6 に縮む。
> また Phase 1 の `leak` は輸入＋対外資産、Phase 3 の `leak` は輸入のみで、
> **両者は同じものを測っていなかった**。

### 4.2 基軸特権をオフにすると A も破綻しうる

u ≥ 0.015 では D が、u = 0.05 では A も30年以内に債務超過する。
v7 では基軸ブロックは `reserve_thr = 1.5`（他は 0.9）で守られていた。
**この保護を外すと、基軸国であることは自動的な安全を意味しない。**
決済手段の発行から導出される優位（設計 D）がこれを置き換えるかは、
まだ検証していない。

## 5. 実装上の修正（実装中に発見した4件）

1. **世界容量の成長を輸出能力で加重していた。** 供給能力は大きく低成長なブロックに
   偏り、輸入需要は小さく高成長なブロックに偏るので、ベースラインでも年間2%程度
   ギャップが開き、給付がなくても世界物価が30年で1.72まで上がっていた。
   需要加重に修正し、ベースラインは 1.039 になった。
2. **為替の調整が加算的だった。** v7 の `de = −2·flow` は、為替が 2.0 でも 0.2 でも
   同じ幅だけ動かす。閉じた世界では誰かが必ず黒字を出すので、黒字国の為替は
   下限 0.05 に張り付いて反応しなくなった。比例調整 `de = −2·flow·e` に変更し、
   支出切替の戻し項を明示した。
3. **破綻ブロックの NFA を計上していなかった。** 状態更新のループ内で加算していたため、
   破綻したブロックの分が落ち、`Σ ΔNFA = 0.984` と恒等式を破っていた。
   全ブロックについてループ外で加算する形に修正。
4. **破綻ブロックの輸入をゼロにしていた。** 債務超過は「その国が買い物をやめる」ことでは
   ない。輸入が完全に止まるのは決済制約（設計 D）の現象であり、
   A/B の段階で暗黙に導入すべきではなかった。破綻後も輸入を続ける形に修正した。
   修正前は、どれか1ブロックが閾値を超えた瞬間に世界需要が崩壊し、
   世界物価が**下がって**いた。

## 6. 既知の限界（設計 D への申し送り）

**u ≥ 0.015 で D が破綻すると、対外債務が発散する。**
破綻後も輸入を続けるが（§5.4 の通りこれは正しい）、その資金を供給する主体がいない。
u = 0.03 では D の NFA が GDP の5倍超に達し、その対価として A・B が
過大な債権を積み上げて増価し、為替が壊れる。

**これは決済制約（設計 D）が扱う領域である。** 非基軸ブロックの輸入を
「輸出収入 + 外貨準備 + 新規外貨借入」の範囲に制限すれば、この発散は
輸入の強制圧縮として現れるはずである。

A/B の受け入れ条件は、**この発散が起きない u ≤ 0.01 を主系列として**検証した。
`tests/test_closed_world.py::test_large_transfers_drive_bloc_d_insolvent` が
境界の位置をテストとして固定しているので、D の実装で境界が動けば検出される。

## 7. 次フェーズに影響する設計判断

- **世界容量の成長は需要加重で取る**（§5.1）。供給加重に戻すとベースラインが
  トレンドを持ち、すべての結果がそれを読んでしまう。
- **為替は比例調整で動かす**（§5.2）。閉じた世界では黒字国が必ず存在するため、
  加算的な調整則は必ず下限に張り付く。
- **破綻の定義を分離する。** 現在の「債務超過＝状態更新の停止」は、
  決済能力の喪失とは別物である。D で決済制約を入れる際、
  この2つを混同しないこと。
- **漏出指標を率と額の両方で報告する**（§3.2）。閉じた世界では額が世界物価を動かす。
  Phase 1〜3 の率ベースの結論は、開いた世界における量として読み直す。
- **C（指数化）の前に給付の名目化が必要。** 現在は `T = u·Y_t` のままなので、
  実質価値の目減りは起きない。C が本丸である。

## 8. ユーザーへの質問

1. **世界物価の水準の妥当性**：u=0.01（対GDP比1%）を全ブロックが30年続けると
   世界物価が +41% になる。年率 **1.27%**（無給付ベースラインは 0.13%/年）で、
   モデル内の需給ギャップから出た値だが、`kappa_w = 0.35`（ギャップの価格への伝達）と
   `lambda_w = 0.05`（アンカーへの回帰）は根拠のない選択である。
   キャリブレーションの目標があればご指示ください。

2. **D の破綻境界**：u ≥ 0.015 で D が破綻する。この境界自体を結果として
   報告するか、それとも決済制約の実装後に改めて測り直すか。
   現状は「決済制約なしの上限」としてテストに固定してある。

3. **図1の縦軸**：世界物価を水準で示しているが、論文では
   「無給付比」や「年率インフレ」の方が読みやすい可能性があります。
