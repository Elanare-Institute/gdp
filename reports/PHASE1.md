## 4. 事前予想の検証 — 問いを2つに分ける

事前予想（TASKS.md、**書き換えずそのまま**）：

> **「支配パラメータは eps_supply と land_share」**

この予想は2つの別の問いに分けて判定する必要がある。

| 問い | 目的変数・手法 | 判定 |
|---|---|---|
| **大きさ**：差の *大小* を何が決めるか | `d_leak_abs`（Sobol $S_T$） | eps_supply **棄却**（12/16位） / land_share **棄却**（11/16位） |
| **符号**：差の *向き* を何が決めるか | `sign(ΔLeak)`（LHS層別 $t$、等コストA・B） | land_share **的中**（1位、t=39.9 / 43.7） / eps_supply **棄却**（11–13位、t=1.1 / 1.2） |

**結論**：land_share は「符号を支配する」という意味で**的中**、
eps_supply は**どちらの問いでも棄却**。
第4.1節が大きさ、第4.2節が符号である。

> 土地が効くのは A・B、建設輸入が効くのは D だが、これは地域的な限定条件ではなく
> **一つの統一原理の異なる現れ**である（4.2.2節）。
> 原理は「CLT が買う投入物の逃避性と、現金が流れる先の逃避性の**相対**で符号が決まる」。

### 4.2 符号の支配因子 — 合成変数によるロジスティック回帰

**手法の変更（2回）**。当初は `sign` の Sobol 指数で判定したが、N=512 に上げたところ
上位6個の信頼区間がすべて重なり順位が識別できなかった（bloc A：1位 0.599±0.087 〜
6位 0.546±0.090）。二値目的変数は分散が小さく、Sobol の分解能が足りない。
次に LHS 層別の t 値を用いたが、**これは他パラメータを統制しない周辺比較**である。
最終的に**多変量ロジスティック回帰（標準化係数）を主指標**とした。

**合成変数**（CLT 自身が購入する投入物の逃避性）：

- 実効地代 `eff_land_rent = land_share × (1 − land_discount)`
- 実効建設輸入 `eff_build_imports = m_H × (1 − clt_domestic_sourcing)`

目的変数は「反転＝CLTの方が漏出が大きい」を1とする二値。等コスト基準・LHS 4000点。

### 4.2.2 統一原理の判定 — **支持された（適用範囲を限定して）**

> **「CLT と現金の符号は、CLT が買う投入物の逃避性（実効地代・実効建設輸入）と、
> 現金が流れ込む先の逃避性（家主の海外資産比率 omega0 など）の**相対**で決まる」**

**適用範囲（二段構え）**：

1. **厚生等価基準では、そもそも反転がほとんど存在しない**（99.5〜100%で CLT 優位、表1）。
   この基準では原理の出番がない。
2. **原理が説明するのは、等コスト基準で生じる反転**である（A 35%、B 14%、D 3.6%）。
   同じ財政額を使うとき、どちらの支出経路がより多く国外へ漏れるか、という比較になる。

**両側の係数（標準化、正＝反転しやすい）**：

| ブロック | 反転数 | CLT購入側 | 現金支出側 |
|---|---|---|---|
| A | 1412/4000 | eff_land_rent **+3.25** / eff_build_imports **+0.80** | omega0 **-0.37** / mpc_u **-0.38** |
| B | 567/4000 | eff_land_rent **+4.60** / eff_build_imports **+0.65** | omega0 **-0.38** / mpc_u **-0.22** |
| D | 144/4000 | eff_land_rent **-0.34** / eff_build_imports **+3.80** | omega0 **-3.29** / mpc_u **-0.68** |

- **CLT購入側は一貫して正**：CLT が買う投入物が逃避的であるほど反転しやすい。
- **現金支出側は一貫して負**：現金の流れ込む先が逃避的であるほど、
  現金の方が漏れるので CLT が相対的に有利になり、反転しにくい。

**D で omega0 が −3.29（2位）なのは、原理の現金側の現れ**である。
D は家主の海外資産比率が最も高く（omega0=0.35）、現金給付が家賃経由で家主に渡ると
その多くが海外資産に向かう。CLT の建設輸入（+3.80）と現金の資本逃避（−3.29）が
拮抗しており、**D の符号はこの二つの綱引きで決まっている**。

**D の証拠の強さについて**：D でも同じ原理（CLT購入側 +／現金支出側 −）が働き、
クラス重み付け後の分類性能は A・B と同水準（バランス精度 0.885、PR-AUC のリフト 22.8倍）、
主要係数の 95% 信頼区間もゼロを跨がない。ただし**反転自体が稀（3.6%、144件）なため、
証拠の強さは事象数に制約される**（EPV 18.0 対 A 176.5 / B 70.9）。
区間幅は A・B より広く、この点は結論の確度として明記する。

A・B では土地が、D では建設輸入が前面に出るが、いずれも
「CLT 側の逃避性 − 現金側の逃避性」という同一の量の異なる現れである。
事前予想の land_share が A・B で的中したのは、これらのブロックで
land_share が高く m_H が低い（A: 0.45/0.05、B: 0.40/0.08）ためであり、
D で逆転する（0.30/0.25）のも同じ原理から従う。
**eps_supply はどのブロックでも上位に入らず、棄却される**（係数 +0.09 / +0.50 / −0.60）。

### 4.3 国内調達に費用割増を入れた（追加指示C）

`clt_domestic_sourcing` は当初「無料」だった。これは非現実的なので、
単位建設費に割増 `1 + κ·s` を入れた（κ ∈ [0, 0.5] を新たに振る）。
bloc D・size=0.03 で κ=0.5 のとき、全量国内調達すると建設輸入は 0.00105 → 0 になる一方、
財政コストは 0.00510 → 0.00720（**+41%**）に増える。**トレードオフが入った。**

割増を入れてもなお `clt_domestic_sourcing` は上位に残る
（`d_leak_abs`／厚生等価／D で4位 0.850、`ratio` では**1位** 0.830）。
`sourcing_cost_kappa` 自身も10位（0.729）である。

> **注意**：`ratio` で sourcing が1位になるのは、**κ による財政コスト経路を含んだ順位**である。
> 4.4 のとおり κ=0 では sourcing と m_H は輸入経路上で完全に同一なので、
> この1位は「国内調達というレバー固有の強さ」ではなく、
> 「輸入を下げる効果＋財政コストを上げる効果の合計」を表している。

### 4.4 「政策 > 構造」の非対称性は**撤回する**（追加指示B）

前回「非対称性は範囲を揃えても消えない」と報告したが、**これは誤りだった**。検証の結果を示す。

**(1) コード上の `m_H` の使用箇所は1つだけ**

```
model/household.py:150    m_H_eff = b.m_H * (1.0 - b.clt_domestic_sourcing)
model/household.py:151    imp_gov = m_H_eff * clt_build
```

家計消費の輸入は `m_F`/`m_G` であり（household.py:142-143）、`m_H` は無関係である。
したがって前回書いた機構説明「m_H は CLT建設と家計消費の両方に掛かるため差に効きにくい」は
**誤りである**。`m_H` と `s` は**同一の式の同一の位置**に現れる。

**(2) κ=0 では2つのレバーは輸入経路上で完全に同一**

実効輸入 `m_H×(1−s)` を同じ幅だけ動かしたとき（bloc D, size=0.03, κ=0）：

| 実効 m_H×(1−s) | m_H 経由の imp_gov | s 経由の imp_gov |
|---|---|---|
| 0.2500 | 0.001050 | 0.001050 |
| 0.1250 | 0.000525 | 0.000525 |
| 0.0000 | 0.000000 | 0.000000 |

**完全に一致する。** 差が生じるのは κ>0 のときだけで、そこでは `s` が財政コストも
動かす（κ=0.5・全量国内調達で fiscal 0.00510 → 0.00720）。

**(3) 範囲を揃えた部分標本での一次効果**

モデルフリーの一次効果指標（条件付き平均の分散比）で比較すると：

| 標本 | m_H | clt_domestic_sourcing |
|---|---|---|
| matched・全体 | **0.0500** | **0.0497** |
| matched・κ<0.1 | **0.1192** | **0.1142** |

**ほぼ同一である。** headline で差が出ていた（0.0127 vs 0.0511）のは m_H の振れ幅が
±50% しかなかったためで、範囲の産物だった。

**(4) 判定**

非対称性の原因は**輸入経路ではなく、κ による財政コスト経路**である。
前回 S_T（0.397 vs 0.851）および S_1（0.036 vs 0.354）で差が残ると読んだが、
**S_T は交互作用を含み、S_1 も κ との交互作用を拾う**ため、
2変数の「固有の効き」の比較には不適切だった。

**結論：「政策 > 構造」は結論として書かない。**
正しくは「国内調達は、輸入依存度を下げるのと**同じ効果**を持つが、
**追加で財政コストを上げる**」である。政策が構造より強いのではなく、
政策には構造にはない副作用がある。

## 5. 想定外の結果（そのまま報告する）

### 5.1 Phase 0 のベースラインは代表的ではなかった

Phase 0 では D と A で符号が反転していた（`leak_per_fiscal`）。しかしパラメータ空間全体では、
同じ D が `leak_abs`／厚生等価で **99.5%** の点で CLT 優位である。
**ベースライン1点の符号を一般的な結論として読んではいけない。**

### 5.2 指標によって符号が変わる（Phase 0 の記述を訂正）

ベースライン点の D で：

| 指標 | ΔLeak (CLT − cash) | 読み |
|---|---|---|
| `leak_per_fiscal` | **+0.087** | CLTの方が漏出が大きい |
| `leak_abs` | **−0.409** | CLTの方が漏出が小さい |

理由：厚生等価でのCLTの財政規模は現金より小さい（Dで0.91% vs 2.50% of GDP）。
分母が小さいので per_fiscal では不利に出る。**どちらも誤りではなく、別の問いに答えている。**
`tests/test_phase0_findings.py::test_sign_depends_on_the_leakage_metric` に固定した。

### 5.3 反転領域は「CLTが買う投入物」で決まる

A・等コストの反転（35%）を層別すると、実効地代を構成する2パラメータが分離する：

| パラメータ | 反転点の平均 | 非反転点の平均 | 差 |
|---|---|---|---|
| **land_share** | 0.698 | 0.392 | **+0.306** |
| **land_discount** | 0.307 | 0.605 | **−0.299** |
| eps_supply | 0.493 | 0.504 | −0.011 |
| m_H | 0.522 | 0.488 | +0.034 |

土地比率が高く取得ディスカウントが小さいとき、すなわち**実効地代が高いとき**に反転する。
図2中央パネルに明瞭な対角境界が出る。一方 **eps_supply はほぼ無関係**（差 −0.011）で、
図2左パネルの境界はほぼ水平である。

> **注**：この層別比較は他パラメータを統制しない周辺比較である。
> 統制した多変量推定は 4.2 節のロジスティック回帰を参照。結論は同じ。

### 5.4 Δseverity の Sobol 指数は、この標本数では解けていない

`severity_noapp` は信頼区間が推定値を上回るものが多く（N=512 で D は 4/16、C は 16/16）、
S_T > 1 も出る（D で 1個、C で 2個）。**severity についての感度の順位は報告しない。**
図1右パネルにその旨を明記した。危機指標は大半の点でゼロになるため分散が小さく、
Sobol推定が不安定になる。**承認どおり Phase 4 の共通乱数に委ね、N の増加は行わない。**

同様に `sign_leak_abs|welfare|D` も16個中4個で信頼区間が推定値を上回る。
厚生等価基準では反転がほぼ存在しない（99.5%）ため符号の分散が小さく、
分解できないためである。**符号の分析は等コスト基準の A・B・D のみで行った**
（この3セルは信頼区間が推定値を下回り、解けている）。

### 5.5 reserve_flight_mode は漏出結果にほぼ影響しない

ベースライン点で `capped` / `v6` / `off` を比較すると、Δleak_abs の差は小数第4位以下
（例：A・等コストで +0.0195 / +0.0185 / +0.0076）。
**逃避流入の産物は危機指標には効くが、漏出指標には効かない。** 主系列を `capped` にした
判断は結論を動かさない。

## 6. 設計判断

1. **相図を A・等コストで描いた**。指示は「符号反転領域の相図」だが、主系列（厚生等価）では
   反転がほぼ存在しない（99.5–100%）ため、その面で描くと一色になり情報がない。
   反転が実在する面（A・等コスト、35%）で描き、対照として厚生等価面を図4に併置した。
2. **`clt_domestic_sourcing` を CLT建設のみに適用**。バウチャーの食料調達には掛けていない。
   政府の建設調達と食料調達は別の政策判断であり、混ぜると解釈できなくなるため。
3. **Sobol は `calc_second_order=False`**。設計サイズが N·(k+2)=9,216 に収まり、
   1時間制約を満たす。二次交互作用が必要なら Phase 2 以降で別途。
4. **feasibility は構成で担保**。sub_F+sub_G+sub_H ≥ 0.95 のとき sub_H をクリップする。
   結果として棄却点が0件になり、サンプルの偏りが生じない。
5. **Phase 0 のレポートを事後修正した**（表1bの追記と指標の明示）。数値は変えていない。
6. **符号の判定手法を3度変更した**：Sobol → LHS層別 t 値 → 多変量ロジスティック回帰。
   Sobol は二値目的変数に対して分解能が不足し、t 値は他パラメータを統制しない。
   最終的にロジスティック回帰（標準化係数）を主、決定木を可視化、t 値を補足とした。
7. **合成変数を導入した**（実効地代・実効建設輸入）。個別パラメータではなく
   「CLT が買う投入物の逃避性」という構成概念が符号を決めるため。
   これは 4.2.2 の統一原理を検証可能な形にしたものである。

## 7. 次フェーズに影響する設計判断

- **u は Phase 2 で {0.03, 0.05, 0.10} に固定する**（承認済み）。
  u は `d_leak_abs` で1位（S_T=0.954）だが、4.2節のとおりこれは主として**尺度効果**である
  （尺度を除いた `ratio` では u は3位、1位は clt_domestic_sourcing）。
  それでも固定するのは、水準ごとに漏出の目盛りが変わるため、
  異なる u を混ぜると他パラメータの効果が読みにくくなるからである。
- **Phase 2 では合成変数（実効地代・実効建設輸入）を出力に含める**。
  4.2.2 の統一原理が家計異質化の下でも成立するかが、Phase 2 の検証点になる。
  とくに CLT 入居者と市場賃借人で「誰にとっての実効地代か」が分かれる。
- **Phase 4 の severity 解析には共通乱数と大きなNが必要**（5.4）。承認どおり Phase 4 に委ねる。
- **κ（国内調達の費用割増）は Phase 2 以降も維持する**。4.4 のとおり、
  これが無いと国内調達が無料の万能策に見えてしまう。
