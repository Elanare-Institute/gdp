# v7 — frozen

The Phase 0–3 model, kept verbatim as the record of what produced
`reports/PHASE0.md` … `PHASE3.md`. **Do not modify.**

v7 rests on two premises that v8 abandons:

- **transfers are pinned to current GDP** (`T = u · Y_t`), so a transfer never
  loses real value to inflation and the self-defeating loop of
  indexation → fiscal cost → demand → inflation cannot arise;
- **the world is open**: one bloc's leakage leaves the model rather than
  arriving as another bloc's export, so there is no world price level and no
  adding-up across blocs.

Its results are therefore results *under those premises*, not results about
the world the paper argues over. They are preserved, not retracted.

The live model is `model/` (v8). The v7 regression tests live in
`tests/legacy/`.
