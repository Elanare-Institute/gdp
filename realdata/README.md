# Asset-Relative Wage Index（実データ版）

論文 "The Wage That Vanished" の Figure 4 を、シミュレーションではなく**実際の経済データ**から
構築する。1971–2024の米国賃金を複数の資産価格で割り、
「名目↑ / CPI実質→ / 資産建て↓」を実証する。

## 実行方法

```bash
uv sync --extra dev
uv run python -m src.fetch_data      # 全データを data/ にキャッシュ
uv run pytest tests/ -v              # 20件の整合性テスト
uv run python -m src.plot_figures    # 図4枚と results_realdata.json を生成
```

キャッシュ済みなら再ダウンロードしない。`--refresh` で強制再取得。

## 主要な結果（1971 = 100、2024年）

| 系列 | 指数 | |
|---|---|---|
| 名目賃金 | **831** | 右肩上がり |
| CPI実質賃金 | **107** | 53年でほぼ横ばい |
| 商品建て（PPI） | **124** | **賃金が商品に勝っている** |
| 住宅建て | **50** | 半減 |
| 株式建て | **15** | 崩落 |
| 金建て | **14** | 崩落 |
| 株式建て（配当再投資） | **5**（2023年） | さらに激しい |

**論文の核心的区別が実データで確認された。** wealth-storing assets（金・株・住宅）
に対してのみ賃金は崩落し、consumption goods（商品）に対しては崩落しない。
仕様が要求した「PPIが賃金に負けることを確認せよ」は指数124で確認済み。

## 仕様書からの逸脱（すべて実測に基づく）

### 1. 指定された2つのFREDソースが死んでいる

| 仕様の指定 | 状態 | 採用した代替 |
|---|---|---|
| `GOLDPMGBD228NLBM` | **廃止**（HTMLを返す） | datahub `gold-prices`（1833–2026 月次） |
| `SP500` | **2016年以降のみ**（FREDが10年で打切） | datahub `s-and-p-500`（Shiller, 1871–2026） |

代替が正しい系列であることは、仕様が独立に記した基準値との一致で相互検証した：

- 金1971年平均 = **$40.92**（仕様「約$41」）
- S&P 1971年1月 = **93.49**（仕様「約92ポイント」）

これらは `tests/test_indices.py::test_source_benchmarks_match` に固定してあり、
データソースが差し替わったら気づける。

Stooq は JavaScript proof-of-work 化しており**スクリプト取得不可**（検証済み・不採用）。

### 2. 配当再投資系列は1871年まで遡れる

仕様は「Total Return は1988年以降しか取れない」としているが、採用したShillerデータには
配当列があり全期間で構築できる。ただし配当は遅れて公表されるため**2023年で打ち切り**。
図では点線で併記（2024年の値ではないことを明示するためラベルに年を付す）。

### 3. fig4b：低下幅は起点に依存する（仕様の予想と逆）

仕様は「定性的パターンは起点に依存しない」と予想するが、実測は否定した：

| 起点 | 2024指数 |
|---|---|
| 1971 | 14 |
| 1975 | 43 |
| 1985 | 46 |
| **1980** | **112（上昇・符号反転）** |

1980年はハント兄弟の金バブル（年平均$608 vs 1975年$161）。**バブル頂点にアンカーすると
賃金が有利に見える。** 4起点中3つで54–86%の低下なので結論は生き残るが、
「起点に依存しない」とは言えない。図中に理由を明記した。

### 4. fig4c：2つの住宅指標は「整合」しない

仕様は「両者が整合することを確認」とするが、2024年で**14ポイント乖離**（MSPUS 82 vs
Case-Shiller 68）。方向は一致するが水準は一致しない。Case-Shillerは品質調整済み
リピートセールス指数、MSPUSは売れた住宅の規模・構成に左右される粗い中位値なので、
**乖離は予期される**。

### 5. 仕様JSONテンプレートの数値誤り

`wage_1971_nominal: 3.45` は1月値。**1971年の年平均は 3.63**。
本実装は全系列を年平均に統一しているので3.63を採用。

## 国際比較（fig4d）のデータ可用性

仕様が挙げたソースはほぼ全滅したため、代替を探索・実取得検証した。

**死んでいるもの**：FREDの日本賃金系列すべて（`JPNWAG`, `LCEAMN01JP*` 等。
OECD MEI系列はFREDから撤去）、ILOSTAT の `rplumber.ilo.org`（200だが本文0バイト）、
`webapps.ilo.org/ilostat-files/`（404）。

**採用したもの**：

| 国 | ソース | カバレッジ | 2024指数(2000=100) |
|---|---|---|---|
| 米国 | FRED `AHETPI` | 1971–2025 | 25 |
| 日本 | OECD SDMX `AV_AN_WAGE` | 1990–2025 | **9** |
| ブラジル | ILOSTAT SDMX | 1995–2025 | 31 |
| インド | ILOSTAT SDMX | 2005–2025（11点） | 40※ |

※インドは2000年のデータがないため2005=100。水準は他国と直接比較できない（図中に明記）。

**中国は除外した。** ILOSTATは一見1971–2022をカバーするが、それは下位セクター系列の
混在である。`ECO=*_TOTAL` かつ `CUR_TYPE_LCU` の clean 系列に絞ると**1997年で切れる**ため、
目標期間2000–2024が空になる。仕様の「取れない国は無理に含めない」方針に従った。

**日本の注意点**：OECDのカバレッジが1990年（バブル絶頂）から始まるため、
**崩落幅が最大化される方向のバイアス**を持つ。1971–1989は登録APIキーなしでは取得不可。
図中に明記した。

### SDMX APIの正しい呼び出し方（試行錯誤の記録）

- **OECD**: キーは `all` でなければならない。`JPN.A.....` のような次元指定は404。
  ダウンロード後に `REF_AREA` / `UNIT_MEASURE` / `PRICE_BASE=="V"`（当年価格）で絞る。
  `PRICE_BASE=="Q"` は実質値なので金建て計算には**使ってはいけない**。
- **ILOSTAT**: 国で絞らないと**504タイムアウト**。`/{COUNTRY}.A.....?startPeriod=1971`。
  ヘッダに `Accept: application/vnd.sdmx.data+csv;version=1.0.0` が必要。
- **FRED**: 一部のカスタムUser-Agent文字列を拒否する（無応答になる）。
  `curl` の既定UAを使うこと。`src/fetch_data.py` は `requests` ではなく `curl` を
  トランスポートに使っている（この環境では `requests` がFREDに対してハングするため）。

## 実装上の判断

- **全系列を年平均に統一**。月次・四半期・年次が混在するため、年平均が最も頑健で、
  仕様の「1971年の金価格は年平均を使う」という指示とも整合する。
- **共通基準年への補間**。国際比較で基準年（2000）のデータが欠けている国は、
  前後の年から線形補間して**本当に同じ基準**に揃える。補間すら不可能な国
  （インド：2000年が範囲外）は自国の初年を基準とし、**比較不能であることを図に明記**する。
- **ブラジルの通貨切替**。1989–1990の値はクルザード/クルゼイロ建てでレアル建てと
  比較不能なため、`start_year=1995` で除外している（テストで固定）。
- **取得失敗は例外**。黙って部分的な図を出さない。

## 論文執筆時に明記すべき事項

- 金・株のソースはFREDではなく datahub/Shiller ミラー（FRED該当系列は廃止/短縮）
- 金建て賃金の低下幅は起点に依存する。1980（金バブル頂点）起点では上昇に転じる
- Case-Shiller と MSPUS は方向は一致するが水準は約14ポイント乖離する
- 中国は clean な総経済系列が1997年で切れるため国際比較から除外
- 日本は1990（バブル絶頂）起点のため崩落幅が最大化されるバイアスを持つ
- インドは2005基準であり、他国と水準を直接比較してはならない
- S&P は price only を基本とし、配当再投資込み（2023年まで）を併記
