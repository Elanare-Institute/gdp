# v8 フェーズ A・B 仕様 — 世界を閉じる／世界インフレ

**対象**：CLAUDE.md の設計 A（世界を閉じる）と B（世界インフレ）のみ。
C（給付の指数化）・D（決済制約）・E（制度比較）は本仕様の範囲外。

**受け入れ条件**（CLAUDE.md「進め方」より）：
全ブロックが同一の現金給付を行ったときに**世界物価が上がる**ことを確認する。

---

## 用語について

**「CLT」は「非逃避的な現物資産として供給される住宅」の代表例である。**
コミュニティ・ランド・トラストという特定の制度形態の忠実な再現ではない
（借地条件・再販価格の算式・ガバナンス構造はモデルに入っていない）。
モデルが表現しているのは、議論が依拠する二つの性質だけである：
給付が金額ではなく実物量であること、その支出が輸入ではなく国内建設に
偏って向かうこと。この二つを持つ制度なら、モデル内では同じ挙動を示す。

**「バウチャー」は対照であって政策提案ではない。**
現物の食料給付が現金と等価になる領域（インフラマージナル）と
そうでない領域を確定するために置いている。



## 0. 記法

- ブロック `i = 0..N-1`、四半期ステップ `t`。
- 実質量は世界財の単位、名目量はブロック `i` の自国通貨建て。
- `e_i`：自国通貨／世界通貨の為替レート（上昇＝減価）。基軸国は `e = 1` を定義とする（§D で緩める）。
- 世界価格 `P_w`：世界財の世界通貨建て価格。初期値 1。

## 1. 財の構造（A の前提）

v7 は財を F（食料）/ G（一般財）/ H（住宅）に分けていた。v8 では貿易可能性で
二分する：

| 区分 | 含まれるもの | 貿易 | 価格 |
|---|---|---|---|
| **貿易財 T** | 食料 F・一般財 G のうち輸入される部分、建設資材 | 世界市場で取引 | `P_w`（世界通貨建て） |
| **非貿易財 N** | 国内サービス、住宅サービス、国内調達の建設 | ブロック内で取引 | `P_N,i`（自国通貨建て） |

家計の効用と予算制約は v7 の Stone–Geary/LES を保持するが、価格は
`p_F = e_i · P_w · (食料の貿易比率)` のように**世界価格と為替から合成**する。
v7 の `m_F`/`m_G`/`m_H` は「その財の輸入比率」としてそのまま使える。

> **設計判断 1**：F/G/H の3財構造は保持し、貿易可能性は `m_*` で表す。
> 財を T/N に作り直すと Phase 2 の家計異質化の移植が壊れるため。
> `m_F = 0.3` は「食料需要の30%が世界市場から来る」の意味を変えずに、
> その部分の価格が `e_i · P_w` になる、と読み替える。

## 2. A：世界を閉じる

### 2.1 貿易シェア行列

規模と開放度から固定の行列 `S` を作る。`S[i][j]` はブロック `i` の輸入のうち
`j` から買う割合。

```
w_j    = gdp_j · openness_j              # j の輸出供給力
S[i][j] = w_j / Σ_{k≠i} w_k   (j ≠ i),  S[i][i] = 0
```

各行は 1 に和が取れる。自国からは輸入しない。

> **設計判断 2**：行列は固定（時間不変）。規模・開放度は初期値を使う。
> 内生化すると A の恒等式の検証が貿易配分の動学と混ざる。

### 2.2 加総条件

- ブロック `i` の実質輸入需要 `M_i`（世界財単位）を家計・政府ブロックから計算。
- ブロック `j` の輸出 `X_j = Σ_i S[i][j] · M_i`。
- **恒等式1**：`Σ_i M_i = Σ_j X_j`（定義から自動的に成立、テストで固定）。
- 経常収支 `CA_i = X_i − M_i`。**恒等式2**：`Σ_i CA_i = 0`。

### 2.3 資本収支

v7 の `flow`（資本流出入）を、世界で相殺するよう組み直す。

```
desired_i = openness_i · cap_sens · (r_i − rp_i − r_w)      # 各ブロックの希望流入
net_i     = desired_i − (Σ_k desired_k) · share_i           # 世界で和をゼロに
share_i   = w_i / Σ_k w_k                                   # 規模で按分
```

**恒等式3**：`Σ_i net_i = 0`。

> **設計判断 3**：希望流入の総和を規模按分で差し引く形で閉じる。
> 「世界全体では資本は増えも減りもしない」を表す最小の実装。
> v7 の `reserve_flight`（基軸国への逃避流入）は既定でオフ。

### 2.4 経常収支と資本収支の整合

会計恒等式 `CA_i + KA_i = ΔReserves_i` を、v8 では
`CA_i + net_i = Δ(対外純資産)_i` として保持する。
**恒等式4**：`Σ_i Δ(対外純資産)_i = 0`。

## 3. B：世界インフレ

### 3.1 世界の供給能力

```
Ysup_w(t) = Ysup_w(0) · Π (1 + g_w · DT)
g_w = Σ_i share_i · eff_growth_i           # 規模加重の平均成長率
```

短期では固定的で、成長率で緩やかに拡大する。

### 3.2 世界需要と世界価格

世界の貿易財需要 `D_w(t) = Σ_i M_i(t)`。

```
gap(t) = D_w(t) / Ysup_w(t) − 1
Ṗ_w/P_w = κ_w · gap(t) − λ_w · (P_w/P̄_w − 1)
```

`κ_w` は需給ギャップの価格への伝達、`λ_w` は緩やかな回帰。

> **設計判断 4**：世界価格は水準変数として持ち、変化率を需給ギャップで決める。
> v7 のインフレは各国独立だったが、v8 では**世界インフレが共通成分**として
> 全ブロックに入り、各国インフレはそれに国内成分を足したものになる。

### 3.3 各ブロックへのパススルー

```
輸入価格（自国通貨建て） = e_i · P_w
π_i = θ_i · (輸入価格の変化率) + (1 − θ_i) · (国内需給からの圧力)
θ_i = 輸入の GDP 比（パススルー係数、内生）
```

> **設計判断 5**：パススルー係数 `θ_i` を外生パラメータにせず、
> 輸入の GDP 比から決める。CLAUDE.md の「様式ごとの係数を置かない」と
> 同じ理由で、ブロックごとの係数も外から与えない。

## 4. 受け入れ条件のテスト

### 4.1 恒等式（常に成立）
- `Σ_i M_i = Σ_j X_j`
- `Σ_i CA_i = 0`（絶対誤差 < 1e-10）
- `Σ_i net_i = 0`（絶対誤差 < 1e-10）
- 各行 `Σ_j S[i][j] = 1`、`S[i][i] = 0`

### 4.2 A/B の主結果（フェーズの受け入れ条件）
**全ブロックが同一の現金給付を行うと世界物価が上がる。**

- `none`（無給付）と `ubi`（全ブロック同時・同率）を比較し、
  `P_w` の経路が後者で上回ること。
- 単一ブロックのみが給付した場合と比較し、
  **世界物価の上昇が給付を行ったブロック数に対して単調**であること。
- 単一ブロック給付では、そのブロックの漏出が**他ブロックの輸出として現れる**こと
  （v7 では消えていた）。

### 4.3 移植の正しさ
- Phase 2 の家計異質化：同じ入力で v7 と同じ家計配分を返すこと
  （世界価格を v7 の価格に固定した場合）。
- Phase 1 の合成変数（実効地代・実効建設輸入）：定義が保たれること。

## 5. 実装ファイル

```
model/params.py       Bloc, G, 世界パラメータ（κ_w, λ_w）
model/trade.py        貿易シェア行列 S、加総条件、資本収支の閉包
model/world.py        世界価格 P_w、世界供給能力、世界インフレ

```

## 6. 本仕様で決めないこと

- 給付の指数化規則（C）：`T = u·Y_t` を暫定的に保持。A/B の検証には不要で、
  C で置き換える。
- 決済制約（D）：輸入は当面制約されない。
- 基軸国の扱い：`e = 1` 固定と `reserve_*` privilege のオフのみ。
  決済手段の発行からの導出は D で行う。
