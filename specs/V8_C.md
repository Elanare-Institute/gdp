# v8 フェーズ C 仕様 — 給付の指数化と自壊の循環

**対象**：CLAUDE.md の設計 C。
D（決済制約）・E（制度比較の位置づけ）は本仕様の範囲外。

---

## 用語について

**「CLT」は「非逃避的な現物資産として供給される住宅」の代表例である。**
コミュニティ・ランド・トラストという特定の制度形態の忠実な再現ではない
（借地条件・再販価格の算式・ガバナンス構造はモデルに入っていない）。
モデルが表現しているのは、議論が依拠する二つの性質だけである：
給付が金額ではなく実物量であること、その支出が輸入ではなく国内建設に
偏って向かうこと。この二つを持つ制度なら、モデル内では同じ挙動を示す。

**「バウチャー」は対照であって政策提案ではない。**
現物の食料給付が現金と等価になる領域（インフラマージナル）と
そうでない領域を確定するために置いている。



## 0. なぜ必要か

論文の中心的主張 (1)：

> 周辺国が現金 UBI を続けられないのは、債務の評価替えではなく、
> **インフレによる給付の実質価値の喪失と、名目増額が再びインフレを生む循環**による。

現行の v8 は給付を `T = size · Y_t`（現在 GDP 比）で決めている。
`Y_t` は名目 GDP なので、**インフレが起きれば給付額も自動で同率増える**。
実質価値は定義上一定で、目減りが起きない。この経路がモデルに存在しない。

C はこれを、**名目額として保持し、実質価値を内生的に決まらせる**構造に置き換える。

---

## 1. 指数化規則

給付を名目額 `T_i(t)` として持ち、その更新規則を**政策変数**にする。

| 規則 | 更新 | 意味 |
|---|---|---|
| `gdp_linked` | `T_i(t) = size · Y_i(t)` | **現行の挙動**。感度分析として保持 |
| `fixed_nominal` | `T_i(t) = T_i(start)` | 名目固定。実質価値はインフレ分だけ目減りする |
| `cpi_indexed` | `T_i(t) = T_i(t−1) · (1 + π_i(t−1))` | CPI 連動。実質価値を維持しようとする |

**主系列は `cpi_indexed` と `fixed_nominal` の両方**（CLAUDE.md）。
`gdp_linked` は「現行 A/B と同じ結果になること」を回帰テストで固定するために残す。

> **設計判断 1**：`cpi_indexed` は**前期のインフレ**に連動させる。
> 同期のインフレに連動させると、給付がインフレを生み、そのインフレが
> 同じ期の給付を増やす同時方程式になる。現実の指数化も遅れを伴う。

> **設計判断 2**：CLT の「給付」は現物なので指数化の対象が違う。
> 住宅の実物量は物価で目減りしないため、`fixed_nominal` と `cpi_indexed` の
> 区別は**建設費の支払い**にのみ適用する。
> これが CLAUDE.md §E (i)「インフレ下でも実質価値が保たれる（現物であるため）」の
> モデル内実装である。

---

## 2. 自壊の循環

`cpi_indexed` では次の経路が閉じる：

```
インフレ π_i ↑
  → 名目給付 T_i ↑（指数化）
  → 財政コスト ↑ かつ 需要 ↑
  → 輸入 ↑ → 世界需要 ↑ → 世界物価 P_w ↑
  → 輸入価格 ↑ → π_i ↑
```

**この循環がどこで非線形に強まるかを反応面として示す。**
閾値で「発散する条件」を特定しない（CLAUDE.md の方針）。

`fixed_nominal` ではこの循環が働かない代わりに、
**給付の実質価値が目減りする**。どちらも問題であり、
どちらがましかは配置による。それを反応面で示す。

## 3. 報告する量（`specs/V8_COLLAPSE.md` に追加）

### P3. 給付の実質価値の推移

```
real_value_i(t) = T_i(t) / P_i(t)
```

`P_i(t)` はブロック `i` の物価水準（初期 1、`π_i` で更新）。

報告：**導入時に対する比の推移**、ブロック別。
**「維持できなくなったブロック数」は数えない**（閾値を要するため）。分布として報告する。

### 既存の量への追加

`cpi_indexed` では財政コストが内生的に増えるので、
**財政コストの対GDP比の推移**も報告する。

## 4. κ_w の選び直し

現行の `kappa_w = 0.35` では無給付ベースラインの世界インフレが年 0.13% で、
**低すぎる**（レビュー指示）。

**主系列の κ_w は「無給付ベースラインの世界インフレが年 1.5〜2%」になる値を選ぶ。**
選び方を根拠として明記する。

`λ_w` は 0.02 / 0.05 / 0.10 を感度分析。
**(κ_w, λ_w) 平面の反応面**を出す（単一値へのキャリブレーションはしない）。

> **設計判断 3**：κ_w を上げるとベースラインも給付時も両方インフレが上がる。
> 「ベースラインを 1.5〜2% に合わせる」ことは、
> **給付の効果をベースラインからの差分として読む**ための正規化であって、
> 現実の世界インフレを再現する主張ではない。レポートに明記する。

## 5. 実装

```
model/indexation.py   指数化規則、名目給付の状態、実質価値の計算
model/params.py       G.indexation、Bloc の名目給付状態
model/core.py         給付額を毎期 indexation から取る
model/household.py    size ではなく名目額を受け取る
```

**`gdp_linked` を既定にし、A/B の出力を再現すること**（v8 内の回帰）。

---

## 6. テストで固定すること

- `gdp_linked` で A/B と**同一の出力**になること（v8 内の回帰）。
- `fixed_nominal` で、インフレ下の実質価値が**単調に下がる**こと。
- `cpi_indexed` で、実質価値が `fixed_nominal` より**高く保たれる**こと。
- `cpi_indexed` の財政コストが `fixed_nominal` より**大きくなる**こと。
- CLT の現物部分が、指数化規則によらず**実質量を保つ**こと（設計判断 2）。
- 自壊の循環が閉じていること：`cpi_indexed` で世界物価を外生的に上げると、
  給付額・財政コスト・世界需要がいずれも増えること。
- 前期連動であること（同期連動なら同時方程式になり、これを検出できる）。

---

## 7. 本仕様で決めないこと

- 決済制約（D）：輸入は当面制約されない。
- 基軸国の扱い：`reserve_privilege` は既定オフのまま。
- 現物比率（mix）の反応面：C で `clt` と現金の混合が可能になった時点で追加する。
