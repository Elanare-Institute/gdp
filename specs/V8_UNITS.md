# v8 名目・実質の扱い 仕様

**背景**：世界需給ギャップが「名目輸入額 ÷ 実質供給能力」で計算されていた。
物価が上がると需要が増えたように見え、それがさらに物価を上げる——
**単位の混同が正のフィードバックを作っていた**。κ_w を上げた途端に発散したのはこれによる。

同種の混同を防ぐため、モデル内の全量について名目／実質を確定させ、
各接続点でどちらを使うかを定める。

---

## 用語について

**「CLT」は「非逃避的な現物資産として供給される住宅」の代表例である。**
コミュニティ・ランド・トラストという特定の制度形態の忠実な再現ではない
（借地条件・再販価格の算式・ガバナンス構造はモデルに入っていない）。
モデルが表現しているのは、議論が依拠する二つの性質だけである：
給付が金額ではなく実物量であること、その支出が輸入ではなく国内建設に
偏って向かうこと。この二つを持つ制度なら、モデル内では同じ挙動を示す。

**「バウチャー」は対照であって政策提案ではない。**
現物の食料給付が現金と等価になる領域（インフラマージナル）と
そうでない領域を確定するために置いている。



## 0. ニュメレール

- **実質量**：初期時点の世界財を単位とする。
- **名目量（自国通貨建て）**：ブロック `i` の通貨。初期時点で 1 単位＝世界財 1 単位。
- **世界価格 `P_w`**：世界通貨建ての世界財価格。初期 1。
- **為替 `e_i`**：自国通貨／世界通貨。上昇＝減価。

## 2. 接続点の規則

| 接続点 | 使う量 | 理由 |
|---|---|---|
| **世界需給ギャップ** | `imports_q` / `capacity` | **両方とも実質**。混ぜると単位由来の正フィードバックが生じる |
| **世界容量の成長加重** | `imports_q` | ギャップと同じ量で加重する |
| 貿易シェア行列の配分 | `imports`（名目） | 国際収支は名目建て |
| 経常収支 `CA` | `imports`, `exports`（名目） | 同上 |
| 資本収支 `KA` | 名目 | 同上 |
| 対外純資産 `ΔNFA` | 名目 | 同上 |
| 家計の予算制約 | `buy`（名目） | 支出＝所得 |
| 効用 | `x`（実質） | 効用は数量の関数 |
| 住宅市場の清算 | `x[H]` と `S0`（実質） | 数量で需給が一致する |
| 漏出（世界市場への圧力） | **実質** | `V8_RELEAK.md` の「額」は実質量として読む |
| 漏出（一国の対外収支） | 名目 | 国際収支上の量 |

> **設計判断 1**：`imp_c / P_w` は実質輸入の正しい近似では**ない**。
> 輸入財の価格 `pF = (1−m_F) + m_F·e·P_w` には国内成分が含まれるので、
> 世界価格だけで割ると過剰にデフレートする
> （物価5倍で真の数量は 0.60 倍だが、`imp_c/P_w` は 0.27 倍）。
> **数量は家計ブロックから持ち回る。再構成しない。**

> **設計判断 2**：`Y` は実質 GDP である。したがって `size · Y` は**実質給付**であり、
> インフレで目減りしない。これが v7 から引き継いだ構造であり、
> **フェーズ C が置き換える対象そのもの**である。

## 3. 世界供給能力の決め方

**世界容量は、無給付ベースラインで実現した実質需要の経路とする。**
全配置がこの同一経路を共有する。

### 3.1 なぜベースラインか

容量をその配置自身の需要に追随させると、**給付が需要を増やしたとき容量も増え、
需給ギャップが自動的に埋まって世界インフレの圧力を過小評価する。**
それはまさに本研究が測ろうとしている量である。

ベースラインの実現値を使えば、給付が生む需要増は容量に反映されない。

### 3.2 なぜ想定成長率ではないか

`base_growth − decay·t` は各ブロックが**実際には実現しない**。
財政・資本移動・債務返済がいずれも産出を想定値から動かす。
放置すると容量が30年で実質需要を3%上回り、
**無給付の世界が年 −0.45% のデフレに漂う**。
モデル内に原因のないトレンドであり、以後のすべての結果がこれと対比して読まれてしまう。

### 3.3 不動点として解く

ベースラインの需要をそのまま採用しても不動点にはならない。
容量が変われば価格が変わり、価格が変われば実質需要が変わるためである。
**反復して収束させる**（各回が前回の実現需要を採用する。
価格から数量へのフィードバックが弱いので数回で収束する）。

結果：**無給付の世界は需給ギャップが厳密にゼロ**で、世界物価は 1 のまま動かない。
これは参照経路の正規化であって、「供給が需要に見合う」という主張ではない。
給付を行う配置は、この固定された容量に対してギャップを開く。

### 3.4 実装

```
baseline_capacity_path(blocs, g)   無給付で走らせ、不動点反復して容量経路を得る
simulate(blocs, g)                 その経路を渡して本番を走らせる
_run(blocs, g, capacity_path)      capacity_path=None なら想定成長率で伸ばす
```

経路は構造パラメータでキャッシュする（配置が違っても容量は同じなので）。

## 4. テストで固定すること

- `household_block` の `imp_q` が、世界価格を上げたとき**減る**こと
  （名目 `imp_c` は増えてもよい）。
- `imp_q` が `m_F·x[F] + m_G·x[G]` と一致すること。
- 世界需給ギャップが `imports_q` と `capacity` から作られていること
  （名目量が混入していないこと）。
- 世界価格を一様に上げても、実質配分（`x`）が価格比のみに依存すること。
- 経常収支・資本収支・NFA の恒等式が**名目量**で成立すること。
- 物価が上がると自動的に増える量が、需給ギャップの計算に入っていないこと。
- **容量が配置に依存しないこと**：給付ありの配置で容量経路が
  無給付ベースラインと一致すること。
- 無給付ベースラインの需給ギャップが全期間で厳密にゼロであること。
- 給付が需要を増やしたとき、容量ではなくギャップが動くこと。
