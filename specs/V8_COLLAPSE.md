# v8 世界レベル圧力指標 仕様

**目的**：ある配置が世界にどれだけの圧力を、どの向きに生むかを測る。
一国の危機指標（`severity` / `insolvent_year` / 債務比率）とは**別の対象**である。

**判定はしない。**

---

## スコープ（本モデルが扱う範囲）

**扱うのは、国家が経済的に維持できなくなる手前までである。**
決済制約に拘束され、輸入が圧縮され、受給者が基礎需要を満たせなくなり、
債務超過や決済不能に至る、というところまで。

**経済破綻の後に起きることは扱わない。**
政府の権威と正当性の喪失、内乱、その外部化としての戦争、難民の流出入。
これらは社会・政治の領域であり、モデルに入れれば係数の置き方が
結論を決めることになる。

示せるのは、ある配置がどれだけの圧力を生み、
どの構造のブロックが先に限界に達するかまでである。
**現実の破綻の可否も、その後の展開も、本モデルは予測しない。**

## 用語について

**「CLT」は「非逃避的な現物資産として供給される住宅」の代表例である。**
コミュニティ・ランド・トラストという特定の制度形態の忠実な再現ではない
（借地条件・再販価格の算式・ガバナンス構造はモデルに入っていない）。
モデルが表現しているのは、議論が依拠する二つの性質だけである：
給付が金額ではなく実物量であること、その支出が輸入ではなく国内建設に
偏って向かうこと。この二つを持つ制度なら、モデル内では同じ挙動を示す。

**「バウチャー」は対照であって政策提案ではない。**
現物の食料給付が現金と等価になる領域（インフラマージナル）と
そうでない領域を確定するために置いている。



## 0. なぜ合否判定を置かないか

現実の世界が破綻に向かうかどうかは、**このモデルに入っていない経路**に大きく依存する：

- ブロック経済化（貿易圏の分断）
- 移民
- 紛争
- 政策転換

モデル内の閾値で「持ちこたえる／破綻する」を判定すれば、
**閾値の置き方が結論を決めてしまう。** それはモデルが知っていることではない。

示せるのは **「トリレンマの制約下で、ある配置が生む圧力の大きさと向き」** までである。
したがって本仕様は連続量の報告のみを定義し、合否は定義しない。

> この方針は CLAUDE.md の絶対ルール
> **「結果の報告は閾値ではなく、符号・順序・パラメータ空間での成立割合で行う」**
> の具体化でもある。

---

## 1. 報告する量

### P1. 世界インフレ（年率）

```
π_w(t) = P_w(t) / P_w(t−1) − 1        （年次サンプル）
```

報告：**経路**、最終値、最大値、平均値。

> **設計判断 1**：最終値を単独で報告しない。
> ブロックが破綻すると需要が消えてインフレが下がるため、
> 最終値が低いことは「落ち着いた」とも「壊れた」とも読める。
> 必ず**最大値・破綻ブロック数・健全需要比**と併記する。

### P2. 供給能力に対する総需要比

```
gap(t) = D_w(t) / Ysup_w(t) − 1
```

報告：**経路**、最終値、最大値。

`D_w` は**輸入のみ**を数える（§3 参照）。

### P3. 給付の実質価値（**C 実装後**）

```
real_value_i(t) = T_i(t) / P_i(t)      # 名目給付 / 自国物価
```

報告：導入時に対する比の**推移**、ブロック別。
「維持できなくなったブロック数」は閾値を要するので**数えない**。
分布として報告する。

### P4. 決済制約に拘束されたブロック数（**D 実装後**）

```
bound(t) = #{ i : 輸入需要_i(t) > 決済可能額_i(t) }
```

これは閾値ではなく**制約が binding かどうか**の事実なので、数として報告する。
推移も報告する（一時的な拘束と恒久的な拘束を区別するため）。

### 付随情報（常に併記）

| 量 | 意味 |
|---|---|
| `insolvent_blocs` | 30年時点で債務超過のブロック数 |
| `first_default_year` | 最初の破綻が起きた年 |
| `demand_share_solvent` | 最終年の世界需要のうち、健全ブロックが占める割合 |

---

## 2. 報告の形

**「どの配置なら世界が持ちこたえるか」ではなく、
「どの配置がどれだけの圧力を生むか」「圧力が非線形に増すのはどこか」を示す。**

給付水準 `u` ／ 現物比率（CLT 比率） ／ 指数化規則を動かしたときの、
**世界インフレと需給比の反応面**を出す。

非線形性の所在は、反応面の曲率として示す（閾値としてではなく）。

---

## 3. 世界総需要の数え方（前回レビュー指示2への回答）

閉じた世界では、あるブロックの資本流出は他ブロックの流入である。
その流入が財需要になるかどうかで `D_w` の数え方が変わる。

**実装を確認した結果、資本流入は到着期には財需要にならない。**
受入国では3経路に作用する：

| 経路 | 効果 |
|---|---|
| `de = −2·flow·e` | 為替（増価） |
| `growth += 0.15·flow` | 成長 |
| `K += flow` | 資本ストック |

財需要への到達は、資本ストックと成長を経由する**間接経路のみ**である。

> **仮定として明記する**：
> **資本流入は請求権の購入であり、到着した期に世界財需要を増やさない。**
>
> 根拠：家計が対外資産を買うのは消費を先送りするためであり、
> 受入側でそれが即座に財の購入に転換されるなら、そもそも貯蓄になっていない。
> ただしこれは会計上の恒等式ではなく**仮定**である。

**感度**：`G.capital_inflow_to_demand`（既定 0.0）で、
流入の一定割合を到着期の世界財需要に直接算入できる。
この仮定は様式の順位を変えない（`reports/V8_RELEAK.md` §3.3）。

| 次元 | 範囲 | 備考 |
|---|---|---|
| 給付水準 `u` | 0 〜 0.05 | |
| 現物比率 | 0（全額現金）〜 1（全額 CLT） | mix として |

| 国内調達率 | 0 〜 1 | |

**反応面として報告する。最適配置の特定には踏み込まない。**

## 5. 分権と基準線

### 5.1 分権（主対象）

各ブロックが**自国のストレスだけを見て**制度と給付水準を選ぶ。
選択規則は Phase 3 の内生ストレス（ΔPV債務 + ΔPVリスクプレミアム + ΔPV減価）を使う。
ブロックは自国のストレスを最小にする配置を選び、**世界指標は見ない**。

### 5.2 協調（基準線としてのみ）

全ブロックが同一の配置を採った場合の同じ量を計算する。
**これは比較のための基準計算であって政策提案ではない。**
協調の制度設計・実現可能性・強制力は本論文では扱わない。
レポートには必ずこの一文を入れる。

### 5.3 報告する一点

分権が生む圧力と、基準線のどの配置が生む圧力を比べ、
**分権がより大きな圧力を生む配置領域があるか**を示す。
「回避できるか」ではなく「圧力の差がどこにあるか」として報告する。

---

## 6. テストで固定すること

- 報告構造に合否フィールドを持たせないこと。
- 圧力の量が、それを駆動するものに対して正しい向きに反応すること。
- **破綻後に沈静化した経路が、静穏な経路と取り違えられないこと**
  （最終インフレ・最大インフレ・破綻数・健全需要比が併記されること）。
- 未測定の量（P3・P4）が `None` であり、0 と区別されること。
- 同じ入力から同じ出力が出ること。

---

## 7. 本仕様で決めないこと

- κ_w / λ_w の値：C 実装後に (κ_w, λ_w) 平面の反応面で扱う。
  主系列の κ_w は「無給付ベースラインの世界インフレが年 1.5〜2%」になる値とする。
- 基軸国の扱い：D 実装後に「基軸国が圧力を免れても他が受ける配置があるか」を確認する。
