# v8 — post_employment（労働需要の世界同時減少）

**対象**：CLAUDE.md の post_employment。**モデル拡張はこれで最後**である。

---

## 0. 前提

AI によるオフィスワークの効率化と、工作機械・自動車の自動運転により、
**世界同時に労働需要が減少する。**

**二本立てで全結果を報告する。**

| 系列 | 内容 |
|---|---|
| `baseline` | 労働需要の減少なし。既存の再分配政策としての比較 |
| **`post_employment`** | 労働需要の減少あり。**本論文の本来の設定** |

---

## 1. 単一の進展度変数

`automation_t ∈ [0, automation_max]` から**すべてを導く**。
個別に係数を置かない。

```
automation(t) = automation_max · (1 − exp(−automation_speed · t))
```

推定値ではないので、**speed と max を複数水準で掃引する**。

### 1.1 導かれる四つ

| 帰結 | 式 | 意味 |
|---|---|---|
| **潜在生産能力の上昇** | `potential ×= 1 + a_capacity · automation` | **実際の生産ではない** |
| **単位生産コストの低下** | 国内財価格 `×= 1 − a_cost · automation` | 国内財を安くする方向 |
| **制約世帯の労働所得の減少** | `c_income_share ×= 1 − a_labour · automation` | |
| **非制約世帯への資本所得のシフト** | 失われた労働所得分が資本所得へ | 家主・対外資産の経路に乗る |

### 1.2 潜在能力の定義と、指標としての限界

```
trend(t)      = 各ブロックの実現トレンド成長（automation とは無関係）
potential(t)  = trend(t) × capacity_multiplier(t)
overhang(t)   = Y(t) / potential(t)
```

**トレンド成長を分母から外している。** トレンドは分子・分母の両方に入る量であり、
automation が生んだものではない。分母を automation の寄与に限ることで、
**automation の効果だけを分離して測る**。

> **これは「稼働率」ではない。名称も `capacity_overhang` とした。**
>
> 分子の `Y` は**トレンド成長と財政刺激で決まり**、需要は
> 給付の国内成分 `d_dom` を通じて `fiscal_mult × 0.08` の係数でしか入らない。
> **非制約世帯の需要は `mpc_u` 経由の支出としてのみ算入され、
> その消費バンドルは解かれていない。**
>
> したがってこの指標が測るのは
> **「automation が加えた能力が、モデルが見ている需要をどれだけ上回るか」**
> であって、経済全体の遊休ではない。
> **「N%の設備が遊休」という読み方をしない。**

### 1.3 需要が生産を抑える経路

`demand_constrains_output`（既定 0）を上げると、需要が潜在を下回る分だけ
成長が抑制される。

```
slack  = max(0, 1 − Y / potential)
growth −= demand_constrains_output × slack
```

**0 は v6 の挙動**（生産はトレンドで決まり、需要に応じない）。
これまでの全フェーズはこの設定である。

**推定値ではないので掃引する。** 特定の値に較正しない。

## 3. 指数化規則と所得連動規則を混同しない

**二つは別物である。**

| 変数 | 何を決めるか | post_employment での扱い |
|---|---|---|
| `income_linkage` | **世帯所得**が経済成長にどれだけ連動するか | **自動的に cpi 側へ寄る**。労働所得が給付に置き換わるため |
| `indexation` | **給付**の名目額をどう更新するか | **制度設計の選択であり、自動的には決まらない** |

> **訂正の記録**：Phase U のレポートで
> 「post_employment では条件3（給付が物価に連動しない）が自然に満たされる」と書いたのは
> **誤りである**。自然に寄るのは `income_linkage` であって `indexation` ではない。

### 3.1 主系列

- **`indexation` の主系列は `cpi_indexed`** のままとする。
  OECD の実態は物価連動が多数派（Van Mechelen & Marchal 2012, GINI DP 55）。
- **`fixed_nominal` は「指数化を怠った場合」として並記する。**
- **本判定は「`cpi_indexed` でも罠が現れるか」で行う。**

---

## 4. 基礎需要の水準

**post_employment では 0.75〜0.95 を主系列とする。**

根拠：`sub_F + sub_G + sub_H = 0.65` は、**働いて所得がある世帯**を前提とした値である。
労働所得が失われた世帯では**支出のほぼ全部が生活費になる**ので、
0.65 という値の前提自体が成り立たない。

0.65 は**回帰のために残すが、主系列からは外す**。

## 5. 報告すべき点（CLAUDE.md）

- **u を下げる** → 基礎需要を満たせない世帯が増える
- **u を上げる** → 周辺国は決済制約に当たり、輸入（特に食料）が圧縮されて
  結局は基礎需要を満たせなくなる

**この二方向の間に逃げ場があるかどうかが中心的な問い。**

Phase U の三分類（既に制約／罠／不動点なし）で、二軸平面上に報告する。

## 6. モデルが主張できる範囲

**このモデルで言えるのは次までである。**

- 労働所得が失われると**制約世帯の需要が比例して落ちる**
  （`labour_multiplier` に対して約1.3倍の緩やかさ。コスト低下が一部を相殺する）
- その結果として決済制約・予算不足がどう動くか

**「経済全体が需要不足に陥る」はモデルの外側である。**
非制約世帯の消費バンドルを解いていない以上、経済全体の総需要は集計できない。
**Discussion で述べるに留め、結果としては主張しない。**

### 6.1 非制約世帯を解いていないことの影響（限界の一本化）

この制約は三箇所に現れる。**論文では一つの限界としてまとめる。**

| 箇所 | 現れ方 |
|---|---|
| Phase C §2.3 | 全体の確保量を集計できない。家賃が家主（非制約世帯）へ移転することは構造から従うが、その使途は計算していない |
| Phase U §6 | 同上。`budget_ratio` は制約世帯のみ |
| post_employment | 失われた労働所得が非制約世帯へ移ることは追えるが、その支出は `mpc_u` 経由の近似のみ。総需要を集計できない |

**共通の記述**：
> 本モデルは制約世帯の家計問題のみを解き、非制約世帯は限界消費性向を通じた
> 支出としてのみ扱う。したがって (a) 経済全体の確保量・総需要は集計できず、
> (b) 制約世帯から非制約世帯への移転が起きることは構造から従うが、
> 移転された所得がどう使われるかは計算していない。
> 稼働率・厚生・需要に関する主張は、いずれも制約世帯に限定される。

## 7. テストで固定すること

- `automation = 0` で `baseline` と**ビット単位で一致**すること。
- 潜在能力が上がっても、需要が足りなければ生産が増えないこと（稼働率 < 1）。
- 制約世帯の労働所得が automation とともに減ること。
- 失われた労働所得が非制約世帯の資本所得に現れること。
- 単位コストの低下が国内財価格を下げること。
- `income_linkage` と `indexation` が独立に効くこと（混同していないこと）。
- `capacity_overhang` が世界・ブロック別に出力されること。
- **`dc = 0` で制約世帯の数量比が `labour_multiplier` に追随すること**
  （コスト低下の相殺により約1.3倍の緩やかさ）。
- **`dc` を上げると循環が働いてさらに落ちること。**

## 8. 本仕様で決めないこと

- 労働市場の詳細（失業率、賃金交渉）：本モデルは家計の所得配分しか持たない。
- 破綻後の帰結：CLAUDE.md のスコープ外。
