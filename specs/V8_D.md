# v8 フェーズ D 仕様 — 決済制約と基軸特権の導出

**対象**：CLAUDE.md の設計 D。

---

## スコープ（本モデルが扱う範囲）

**扱うのは、国家が経済的に維持できなくなる手前までである。**
決済制約に拘束され、輸入が圧縮され、受給者が基礎需要を満たせなくなり、
債務超過や決済不能に至る、というところまで。

**経済破綻の後に起きることは扱わない。**
政府の権威と正当性の喪失、内乱、その外部化としての戦争、難民の流出入。
これらは社会・政治の領域であり、モデルに入れれば係数の置き方が
結論を決めることになる。

示せるのは、ある配置がどれだけの圧力を生み、
どの構造のブロックが先に限界に達するかまでである。
**現実の破綻の可否も、その後の展開も、本モデルは予測しない。**



## 0. なぜ必要か

論文の中心的主張 (3)：

> 基軸国が持ちこたえるのは、インフレを避けられるからではなく、
> **インフレ下でも自国通貨で輸入を決済し続けられる**から。

v7 は基軸国に三つの優位を**外から与えていた**：逃避流入・高い債務閾値・為替減衰。
エディターが批判した「結果を係数で入れる」そのものである。
v8 はこれを既定オフにしてあり、**決済制約だけで基軸国の優位が出るか**を検証する。

また Phase C は「循環は閉じたが30年では暴走しない」で終わった。
決済制約が入れば、周辺国の輸入（特に食料）が圧縮され、
**実質価値の維持そのものが不可能になりうる**。

---

## 1. 決済制約

### 1.1 非基軸ブロック

輸入は外貨で決済しなければならない。使える外貨は3つ：

```
capacity_i(t) = 輸出収入_i(t) + 外貨準備_i(t) + 新規外貨借入_i(t)
```

| 項 | 定義 |
|---|---|
| 輸出収入 | `exports_i`（名目、世界市場から受け取る） |
| 外貨準備 | `reserves_i`（ストック。初期値は GDP 比で与える） |
| 新規外貨借入 | `borrow_i = borrow_limit · gdp_i · (1 − リスク調整)` |

希望輸入 `M_i` が `capacity_i` を超えた分は**強制圧縮**される：

```
realised_i = min(M_i, capacity_i)
rationed_i = M_i − realised_i        # 圧縮された量
```

準備は残差で動く：`reserves_i(t+1) = reserves_i(t) + 輸出 − 実現輸入 + 純資本流入`。

> **設計判断 1**：圧縮は**比例配分**する。食料・一般財・建設資材のどれを削るかは
> 政策判断であり、モデルはそれを決めない。比例配分は中立な既定であり、
> 「食料を優先して削らない」等の規則は感度分析として置く。

> **設計判断 2**：借入枠はリスクプレミアムに反応させる。
> `borrow_i = borrow_limit · gdp_i · max(0, 1 − borrow_sens · rp_i)`
> 債務が膨らんだブロックは借りられなくなる。これは決済制約の一部であって、
> v7 の privilege とは別である（基軸国にも同じ式が適用されうる。§2 参照）。

### 1.2 基軸ブロック

**自国通貨が決済手段なので、この制約がない。** 輸入は希望どおり実現する。

```
realised_reserve = M_reserve
```

これが唯一の基軸特権であり、**他には何も与えない**。

---

## 2. 基軸国の無制限性にも限界を置く

無制限を仮定すると、それ自体が「結果を仮定に入れる」ことになる。
**他ブロックの準備通貨需要**を内生化し、需要が落ちれば基軸国にも制約が及ぶ形にする。

### 2.1 準備通貨需要

他ブロックが基軸通貨を準備として保有したい量は、
**基軸通貨の実質購買力**に反応する：

```
purchasing_power(t) = 1 / P_w(t)          # 基軸通貨で買える世界財の量
demand_for_reserves(t) = base_demand · (purchasing_power(t) / purchasing_power(0)) ** elasticity
```

`elasticity > 0` なので、基軸通貨が購買力を失うほど需要は落ちる。

### 2.2 需要が落ちたときに何が起きるか

準備需要が初期の `reserve_threshold` 倍を下回ると、
**基軸国にも決済制約が及ぶ**：

```
if demand_for_reserves(t) < reserve_threshold · base_demand:
    基軸国も §1.1 の制約を受ける（ただし借入枠は他より大きい）
```

**この閾値がどこにあるかを出力する。**

> **設計判断 3**：`reserve_threshold` と `elasticity` に理論的根拠はない。
> 単一値を選ばず、**掃引して「どの水準で基軸国の特権が失われるか」を反応面として示す**。
> 閾値そのものを結論にしない。

---

## 3. 出力に追加する量

| 量 | 定義 |
|---|---|
| `rationed_blocs(t)` | 決済制約に拘束されたブロック数 |
| `rationing_share_i(t)` | ブロック `i` の圧縮率 `rationed_i / M_i` |
| `reserves_i(t)` | 外貨準備の推移 |
| `reserve_demand(t)` | 基軸通貨の準備需要 |
| `reserve_constrained(t)` | 基軸国が制約下にあるか（真偽） |
| `food_rationing_i(t)` | 食料輸入の圧縮率（**基礎需要に直結**） |

Phase C の実量（制約世帯が確保した F・H）は**そのまま主指標**である。
決済制約は輸入を通じて実量に効くので、両者は同じ表で読める。

---

## 4. v7 privilege との関係

| 機構 | v8 既定 | 備考 |
|---|---|---|
| 決済制約の免除 | **オン**（基軸国のみ） | §1.2。これが導出される優位 |
| 逃避流入 `reserve_flight` | オフ | `reserve_privilege=True` で有効 |
| 高い債務閾値 `reserve_thr` | オフ | 同上 |
| 為替減衰 `reserve_damp` | オフ | 同上 |

**検証すべき点**：`reserve_privilege=False`（既定）で、
決済制約だけから基軸国の優位が出るか。
出なければ「決済手段の発行だけでは基軸国の resilience を説明できない」と報告する。

---

## 5. テストで固定すること

- **制約が無効なら Phase C と同一の出力**になること（v8 内の回帰）。
- 非基軸ブロックで、希望輸入が決済能力を超えたとき実現輸入が圧縮されること。
- 基軸ブロックが（準備需要が高いうちは）圧縮されないこと。
- 外貨準備の収支が閉じること：`Δreserves = 輸出 − 実現輸入 + 純資本流入`。
- **世界の恒等式が圧縮後も成立すること**：圧縮は輸入を減らすので、
  他ブロックの輸出も減る。`Σ CA = 0` が保たれること。
- 準備需要が閾値を下回ると基軸国も制約を受けること。
- 圧縮が食料に及ぶと、制約世帯の食料確保量が減ること（実量への接続）。
- `reserve_privilege=True` が v7 の三つの優位を復活させること（感度分析用）。
