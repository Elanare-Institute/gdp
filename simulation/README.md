# 逃散性（fugacity）による労働分配率低下の統一モデル

Grossman & Oberfield (2022) の over-explanation 問題に対し、**逃散性 φ という単一の
根本原因が4つの proximate cause を同時に生成する**ことを示す数値デモンストレーション。

## 実行方法

```bash
uv sync --extra dev
uv run pytest tests/ -v          # 45件の整合性テスト
uv run python -m src.experiments # 全図と results.json を生成
```

生成物は `output/` に出力される。

## 主要な結果

| | illustrative（仕様準拠） | empirical（実測整合） |
|---|---|---|
| θ_L: φ=0.1 → 0.8 | 0.660 → 0.290（56%減） | 0.660 → 0.580（8pp） |
| over-counting（規約A） | 1.244× | 1.040× |

## 実装で判明した、仕様書の4つの問題

数値検証の結果、指示書 `../simulation_spec.md` の記述をそのままでは実装できない箇所が
4つあった。いずれも解決策とともに実装済み。

### 1. A_i では校正できない（原理的に不可能）

CES一定規模の下で `w·L/Y` は A_i について**0次同次**であり、A_i は θ_L から厳密に消える
（`test_labor_share_invariant_to_tfp` で15桁の不変性を固定）。仕様が想定する A による
θ_L=0.66 への校正は不可能。β でも不可（β≈−0.86 が必要で経済的に無意味）。

**解決**: α^0 の共通シフト κ で校正する。κ=−0.0873 で θ_L(0.1)=0.6600 ちょうど。
α_H−α_L=0.2 のギャップ（セクターを識別する情報）は保存される。

### 2. 均衡系が過剰決定に見えるのは相対価格の欠落

仕様は4未知数・5式に見えるが、賦存制約は残差ではなく**代入**で消せる。相対価格 p を
未知数に加えると **3未知数・3残差**で整合する。F3 は数量シェアでなく**価値シェア**で
なければならない（異質財では数量シェアが定義不能）。

### 3. 楔の二重計上

`w=(1−φβ)·MPL`（チャネルa）と独占的競争のFOC `w=p·MPL/μ`（チャネルd）は同一対象への
二重の式で矛盾する。**乗法的に合成**し、μ は製品市場の楔として両要素に対称に、
(1−φβ) は労働市場の楔として労働のみにかける。資本が残余（純利潤＋交渉レント）を
取得するため **θ_K = 1−θ_L は成立しない**。

### 4. マークアップのスケール依存性

`μ=1+η·φ·(K_i/L_i)` は K/L の**水準**に依存し、賦存量の正規化を変えると μ が変わる。
**比に修正**した：`μ=1+η·φ·(K_i/L_i)/(K/L)`。K=L=1 では数値的に同一。

## over-counting についての最重要の知見

**over-counting は分解規約の産物であり、経済の実体ではない。**
同一モデル・同一パラメータで、規約を変えると結論の符号が反転する：

| 規約 | 個別合計 | 比率 | 解釈 |
|---|---|---|---|
| A 一つずつON（仕様の指定） | 0.4599 | **1.244×** | over-counting |
| B leave-one-out | 0.2855 | **0.772×** | **under-counting（逆転）** |
| C Shapley | 0.3696 | **1.000×** | 構成上厳密 |

原因は代数的である。仕様の関数形は

    θ_L(φ) = (1 − φβ)/μ(φ) · F(α(φ), s_H(φ))

と**乗法分離**するため対数で加法的になり、相互作用項が2次の微小量に留まる。
規約Aのみを報告することは、望む答えを出す規約を選ぶことに等しい。

これは G&O への**より強い**回答になりうる。既存5説はいずれも「自説のみをONにする」
規約Aで推定されており、**その規約自体が重複計上の原因**だと言えるからである。

なお規約Aでも 1.24× に留まり、G&O が報告する 3〜4× には届かない。
**目標値に合わせて調整せず、測定値をそのまま報告している。**

## 低下幅と over-counting のトレードオフ

**実測の低下幅と可視的な over-counting は、このモデル内で両立しない。**
感度パラメータを実測の8ppに合わせて縮小すると、over-counting は 1.244× → 1.040× まで
消える。両者は同一モデルで同時には得られない。この事実自体が報告すべき知見である。

## その他の注意点

- **σ はほとんど効かない**。σ∈[0.5,1.0] で θ_L(φ=0.8) は 0.0005 しか動かない
  （fig5左）。仕様が最も丁寧に出典を付けたパラメータが結果をほぼ動かさない。
  4チャネルは α・μ・賃金に直接作用し、代替を経由しないため。査読対策として重要。
- **実験3には生産性成長を導入した**（`WageConfig.productivity_growth`、既定1.5%/年）。
  これがないとモデルの実質賃金が労働分配率低下を丸ごと被り、CPI実質賃金が半減して
  しまい、仕様が期待する「ほぼ横ばい」にならない。米国で実質賃金が横ばいだったのは
  生産性成長が分配率低下を相殺したためである。均衡計算には一切入らない後処理層。
  `0.0` にすると相殺なしの低下が見える。

## モデル定式化

未知数 **v = (K_H, L_H, p)**、p_L≡1 が numéraire、賦存量は K=L=1 に正規化。

```
F1 = p·MPK_H/μ_H − MPK_L/μ_L            資本の要素価格均等化
F2 = p·MPL_H/μ_H − MPL_L/μ_L            労働の要素価格均等化
F3 = p·Y_H/(p·Y_H + Y_L) − s_H(φ)       産出価値シェア制約
```

FPE を破るのは φ ではなく**マークアップ楔 μ_i**（K_i/L_i がセクター間で異なるため）。
粗の限界生産力は内生的に乖離する。(1−φ_a·β) は両セクター共通のスカラーゆえ F2 から
恒等的に相殺されるので、残差には入れず事後の θ_L 計算でのみ適用する。

**ソルバ**: `scipy.optimize.least_squares(method='trf')`。sigmoid/exp 変換で正値性と
(0,1) を自動保証し、φ 昇順の継続法で前解を初期値に使う。全 φ で残差 ~1e-16。

## 論文執筆時に明記すべき仮定

- s_H(φ) は誘導形の需要条件として課され、相対価格 p が残差として調整する
- 資本は残余取得者：純利潤＋交渉レントが資本に帰属し、θ_K=1−θ_L は成立しない
- A_i は識別されないため 1 に固定（自由パラメータではない）
- η の解釈は K=L=1 の正規化に紐づく
- 実験3の生産性成長率は外生の後処理パラメータであり、均衡には影響しない
